Resistor Combination Calculator

What it does

The Resistor Combination Calculator is a Python program that calculates the total resistance of resistors connected in series and parallel.

It allows users to enter multiple resistor values, displays the calculated results, and keeps a history of previous calculations.

How to run it

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python resistor_calculator.py

My own twist

I added a calculation history feature that allows users to view previous calculations and clear the history when necessary.

I also included input validation to prevent invalid resistor values.
